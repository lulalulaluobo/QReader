# 页面组件

## 现有模式

src/views/reader.ts 的 ReaderView 继承 ItemView，在 onOpen 建立 DOM，在 onClose 释放订阅与引擎。src/util.ts 的 el 负责创建元素，用户或 AI 文本使用 textContent/setText，不插入不可信 HTML。

## 视觉约束

白色/宿主主题背景、留白、弱分隔、灰紫色主按钮；划线支持黄色、绿色、蓝色、粉色、紫色。书架使用两列两行、每页四本的真实封面卡片与最多两行书名，继续阅读独立置顶；封面按原比例缩放，禁止放入横向矮底板。封面高度由剩余视口空间决定，阴影只落在图片上。翻页按钮并入底部导航，极窄容器使用紧凑第二行，保证 44px 点击区；没有第二页则隐藏翻页。紧凑搜索与导入，分类条为全部、未读、已读及用户学科分类。沿用宿主字体、原生图标、Menu 与 Modal。书架页底部入口为书架、复习、设置；阅读页工具栏为独立覆盖层，不增加统计。

阅读页沿用用户指定的纸感正文、运行章节/真实位置提示；中心点按或 Escape 显示/隐藏覆盖正文的顶部与底部操作。面板为目录、三问、笔记、字体排版、背景；CBZ 不显示可伪造文字内容的入口。按章节与原文顺序显示笔记。

宿主导航条只在当前窗口活动视图为 ReaderView 时隐藏。通过 body 活跃态 class 与作用域 CSS 实现，切换视图和插件卸载必须清理；不得写入或永久修改 Obsidian 布局偏好。Reader 画纸根节点使用 `overflow: clip`，不可用 `overflow-x: hidden` 创建可被程序焦点滚动的宽画布：后者会横向移动裁切根及其定位面板。

浅色、深色均需分别定义 iframe 正文和宿主纸张色。原书字体选项不得写 `font-family: inherit` 覆盖原书规则；可更新的动态书页样式应采用同一可替换 stylesheet id，避免重复追加，并清理已删除的声明。

阅读面板必须有对话框语义、焦点陷阱和焦点返回；原生 Setting controls 给可访问名称，ToggleComponent 改作 switch 时须同步 aria-checked 和空格/Enter 键盘切换。

本章三问与独立 AI 解读统一使用底部弹窗，保留原文上下文。三问每题都是可点击的闭卷回答入口；AI 解读只在显式存入笔记后持久化。笔记删除确认必须跨库通知重绘保留；取消不改变记录、Markdown 或高亮。

## 交互与无障碍

选文菜单使用宿主主题背景、清晰边框和阴影，与阅读纸张区分。用户明确要求所有选文功能仅显示图案：复制 copy、AI 解读 sparkles、批注 square-pen、关闭 x、更多 more-horizontal、删除 trash-2、取消批注 eraser、删除确认 circle-check；保留 title/aria-label，不显示按钮文字。主排固定五个 44px 图标且不换行，颜色及更多操作使用独立单行二级浮层，不改变主排高度。划线按钮只显示颜色圆圈：短按确认、长按 450ms/右键/键盘方向下键展开颜色；长按松手不保存，选色后再次短按保存。颜色浮层 Escape 收起并返回圆圈焦点。移动过程中取消长按，关闭菜单及切换页面清理计时器和 pointer capture。

正文高亮是 28% 透明度的柔和色块，EPUB 不描边，PDF 不画底边或外框；色块不改变正文样式、定位或点击能力。菜单色圈仍保留细边缘与选中勾号。

图标按钮必须有可访问名称，表单必须有标签或 aria-label。点击区至少 44px；键盘焦点清晰，窄面板不横向溢出。状态完整：空、加载、失败、重试、禁用。没有数据时不显示假封面或假进度。

## 中英文界面（1.1.4）

界面文案统一使用 `plugin.t()` 与类型安全消息键，动态值通过编号占位符传入，不翻译原书、作者、章节、分类名称、选文、题目、回答或笔记。四页面和设置容器标记 `lang`；图标的 title/aria-label、原生命令、菜单、通知、已知错误同样本地化。未知外部错误保持原文，禁止扫描 DOM 文本自动替换。

语言在原生 Setting 下拉框选择简体中文/English，保存成功后刷新界面。阅读页只替换控制层，不能移动、重挂或重开 iframe；设置路径与提示词编辑草稿、回答与批注草稿保留。宿主 `WorkspaceLeaf.updateHeader()` 使用命名扩展接口并进行方法存在检查。

英文长标签在章节按钮与阅读工具栏允许换行，书架导航使用可收缩的列和紧凑内边距；继续满足窄屏四本封面、单行纯图标选文菜单与 44px 点击区。
