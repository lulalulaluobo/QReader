# 页面组件

## 现有模式

src/views/reader.ts 的 ReaderView 继承 ItemView，在 onOpen 建立 DOM，在 onClose 释放订阅与引擎。src/util.ts 的 el 负责创建元素，用户或 AI 文本使用 textContent/setText，不插入不可信 HTML。

## 视觉约束

白色/宿主主题背景、留白、弱分隔、灰紫色主按钮；划线支持黄色、绿色、蓝色、粉色、紫色。书架使用真实封面卡片网格与最多两行书名，继续阅读独立置顶；手机使用两列紧凑布局，至少四本时首屏显示四卡。紧凑搜索与导入，分类条为全部、未读、已读及用户学科分类。沿用宿主字体、原生图标、Menu 与 Modal。书架页底部入口为书架、复习、设置；阅读页工具栏为独立覆盖层，不增加统计。

阅读页沿用用户指定的纸感正文、运行章节/真实位置提示；中心点按或 Escape 显示/隐藏覆盖正文的顶部与底部操作。面板为目录、三问、笔记、字体排版、背景；CBZ 不显示可伪造文字内容的入口。按章节与原文顺序显示笔记。

宿主导航条只在当前窗口活动视图为 ReaderView 时隐藏。通过 body 活跃态 class 与作用域 CSS 实现，切换视图和插件卸载必须清理；不得写入或永久修改 Obsidian 布局偏好。Reader 画纸根节点使用 `overflow: clip`，不可用 `overflow-x: hidden` 创建可被程序焦点滚动的宽画布：后者会横向移动裁切根及其定位面板。

浅色、深色均需分别定义 iframe 正文和宿主纸张色。原书字体选项不得写 `font-family: inherit` 覆盖原书规则；可更新的动态书页样式应采用同一可替换 stylesheet id，避免重复追加，并清理已删除的声明。

阅读面板必须有对话框语义、焦点陷阱和焦点返回；原生 Setting controls 给可访问名称，ToggleComponent 改作 switch 时须同步 aria-checked 和空格/Enter 键盘切换。

本章三问与独立 AI 解读统一使用底部弹窗，保留原文上下文。三问每题都是可点击的闭卷回答入口；AI 解读只在显式存入笔记后持久化。笔记删除确认必须跨库通知重绘保留；取消不改变记录、Markdown 或高亮。

## 交互与无障碍

选文菜单使用宿主主题背景、清晰边框和阴影，与阅读纸张区分。划线按钮短按确认、长按 450ms 展开颜色；长按松手不保存，选色后再次短按保存。提供独立展开按钮供键盘使用。移动过程中取消长按，关闭菜单及切换页面清理计时器和 pointer capture。

图标按钮必须有可访问名称，表单必须有标签或 aria-label。点击区至少 44px；键盘焦点清晰，窄面板不横向溢出。状态完整：空、加载、失败、重试、禁用。没有数据时不显示假封面或假进度。
