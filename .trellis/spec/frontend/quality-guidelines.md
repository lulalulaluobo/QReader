# 质量与验收

构建命令为 npm run build（TypeScript 检查及 esbuild）。修改进行中不重复构建；所有工作面合入后统一执行。

语言修改须在实际隔离 Obsidian 中验证原生下拉保存/重开、旧配置默认、非法值回退、界面/ARIA/命令/标签页更新；切换时阅读 iframe/document/engine 与 CFI 不变，回答、批注和设置草稿不丢。中英文各检查浅/深色、四页面、窄/宽屏，英文长标签不能溢出。协议端点覆盖中英默认三问、解释、反馈、自定义模板保留、空白回退、中英/JSON 标签与无效响应不落盘；AI 协议固定回复不能当作真实模型质量证明。比较既有历史和原书字节，禁止用翻译迁移用户数据。

## 必验行为

- 实际 Obsidian 隔离 Vault 导入并阅读 EPUB、PDF、FB2（独立/ZIP）、MOBI/KF8、CBZ；验证自然页序、目录/正文、翻页及退出重开位置。
- 新文字格式的批注 CFI 须返回同一原文；现存 EPUB/PDF 的定位、高亮、批注、题目版本、回答/反馈/复习跨重开保持不变。CBZ 只保存图页位置，无三问、文字批注或复习请求。
- 故意传入格式错误、损坏归档与 DRM 文件；确认错误发生于写盘前。比较导入文件与阅读库原书的字节。
- DeepSeek/Agnes 以隔离兼容端点验收官方 URL、模型、各自 Authorization 与无串钥；覆盖 legacy flat settings、探针、错误脱敏、视图重开和请求中途修改配置。没密钥时不得声称真实供应商连接或模型质量。
- 关闭、重载以及打开尚在恢复中的阅读书时，不得丢最后阅读位置、迟到更新已卸载 View，或在读书引擎已销毁时保留内容 hook/listener。
- 回答三问、提交、反馈失败重试不重复保存；历史题目版本和答案完整。
- 到期/即时复习都先闭卷作答，完成后比较历史；未来预约不会被误消耗。
- 损坏、恢复、并发写入和写后不一致时不丢历史。
- 320/375/414/768/1024/1280/1440px 窄宽面板无横向溢出；浅深色与键盘可用。
- EPUB 长按/选区自动滚动扰动后仍在同一整页与 CFI；复制原始文字、关闭面板、翻页、隐藏阅读页返回、重开与模式切换不得丢位置。PDF 跨页复制保持全选区，但批注引用与定位仍限定单页。
- 笔记删除确认跨异步库通知不消失；取消无变化，确认后 `reading.json`、`批注.md` 与可见高亮一致。长中文书名可导入、显示并从磁盘封面缓存重开。
- AI 解读关闭后迟到结果不显示也不保存；显式存入只产生一条批注。三问从第三题先答、其余题补齐、版本切换保留草稿、提交及反馈失败重试均保持版本与记录一致。
- 1.1.2：提示词保存/重开/清空、正文替换与无占位符追加、无效响应不落盘；同一 leaf 连续四页面与原生前进回退，CFI、未提交草稿和问题版本稳定，无后台 iframe/订阅残留；短按保存、长按选色松手不保存、取消不保存、EPUB/PDF 颜色重开和旧黄色；分类新增/分配/搜索组合/已读切换及持久化、首屏四卡。七种宽度浅深色需等待 EPUB resize 250ms 完成再评估稳定布局。
- 1.1.3：两列两行四本及实际图片比例、第五本翻页/筛选搜索重置/回退页码/范围夹取；所有选文按钮无可见文字且有可访问名称，44px 主排五图标始终一行，二级色圈/更多操作不换行。复制/AI 解读/批注/取消批注/取消画线确认仍可用；方向下键/Escape、长按释放与选色不落盘、EPUB/PDF 颜色持久化；四种阅读底色下色块无外框/底边，转换文字格式使用同样绘制。验收产物和公开 Release 附件逐字节一致。

测试只验证消费者可见行为和边界，不检验源代码措辞、属性转发或无意义默认值。暂时的协议服务只可用于验收，不能成为插件假 AI 功能。没有真实供应商密钥时明确报告未验证外部模型。
