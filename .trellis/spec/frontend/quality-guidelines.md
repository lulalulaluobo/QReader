# 质量与验收

构建命令为 npm run build（TypeScript 检查及 esbuild）。修改进行中不重复构建；所有工作面合入后统一执行。

## 必验行为

- 实际 Obsidian 导入 EPUB/PDF，目录与正文可见。
- 翻页/滚动切换、关闭重开保持位置；PDF 画布被回收后再次可见。
- 选择、批注、编辑、撤销与 Markdown 一致；排序跟随原文而非创建时间。
- 回答三问、提交、反馈失败重试不重复保存；历史题目版本和答案完整。
- 到期/即时复习都先闭卷作答，完成后比较历史；未来预约不会被误消耗。
- 损坏、恢复、并发写入和写后不一致时不丢历史。
- 320/375/414/768/1024/1280/1440px 窄宽面板无横向溢出；浅深色与键盘可用。

测试只验证消费者可见行为和边界，不检验源代码措辞、属性转发或无意义默认值。暂时的协议服务只可用于验收，不能成为插件假 AI 功能。没有真实供应商密钥时明确报告未验证外部模型。
