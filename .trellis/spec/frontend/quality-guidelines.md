# 质量与验收

## 连续翻页与首屏速度（2026-10-08）

- 横向分页使用真实文档的连续位移，跨章/物理 PDF 页先保留旧页、准备新页，300ms 移动结束后释放旧页。快速反向导航串行；失败保留旧页、重试不被旧失败阻塞。减少动态效果设置取消动画；关闭/重建取消剩余帧，不能保存中间翻页位置。
- 有效 CFI 与新书首屏不等待全文位置索引。256 字符旧格式索引在首屏后分章生成，关闭取消、不卸载当前文档；全文成功后才发布。旧百分比记录需要索引时仍精确恢复，不把近似章节进度当作实际旧位置。
- 阅读 CSS 在首次排版前应用，后续字体/主题替换同一个节点。EPUB.js 的 reportLocation Promise 只入队，不代表 relocation 帧完成；恢复结束前须等实际帧，目标在视口外时重新定位。
- 独立 Obsidian 检查六格式、同章/跨章移动、旧 CFI 索引一致、重开定位、取消、失败恢复，以及 375px 视口；开书速度在同书同 CFI、同环境下比较。桌面模拟不得称为 Android 真机性能。

## 阅读页听书验收（1.2.5）

- 阅读工具现为目录、笔记、字号、背景、听书五项；默认逐句标色与跟随，临时高亮不写入批注。手动翻页、滚动、跳章或回看批注只暂时暂停跟随，音频沿原序列继续；当前朗读页内允许临时翻看，声音进入下一页的文字时自动返回并持续跟随。边界来自原朗读视口，不能随手动翻页后的浏览页改写。上下滚动、长中文段落、PDF 同页跨屏与物理跨页都适用。暂停再继续或明确选文起读立即恢复跟随；停止按钮退出，换书/离开阅读页释放音频；选文仍暂停。
- 桌面默认系统语音；Android WebView 不支持 Web Speech，自动使用 requestUrl 合成 MP3 + HTMLAudio 的在线方式。无真实 Android 设备时不得将响应布局或桌面音频测试称为真机验收。
- 只在播放后发送当前及至多下一短句，不永久缓存书文或音频。Bing 页面短期会话、随机 IG、SSML 转义、音频签名检查、会话过期重试、服务错误提示必须覆盖。
- 暂停/续读、停止后迟到网络回包、跨源单位、同窗口多个阅读器争用、音频 URL 回收，及含文本五格式/图片 CBZ 边界均须验证。
- 中英、四阅读主题、七宽度验证触控按钮、无溢出、实际原文高亮进入视口；比较原书、历史笔记、批注和生词文件。短句同步不宣称逐字时间戳，首版不承诺锁屏后台。
- 选文菜单主排现为六个图标（含“从这里朗读”），仍保持单行 44px。用 CFI/PDF 字符范围从选区起点所在完整短句起读，重复文字不能定位错；底部播放与打开听书栏前保存的选区均优先于页首，已有标记也可起读。播放中、暂停中、请求等待中改选位置取消旧播放，迟到回包不抢回位置；停止/翻页清掉临时起点。不改复制、查词或持久批注。
- 连续及快速相反方向翻页保持顺序；原朗读页内的过期定位不覆盖新手动翻页，正确的下一朗读页定位优先于之前的临时浏览。重复翻看不得推迟原朗读页边界，自动返回后下一页仍继续跟随。播放栏和阅读工具栏改变视口前捕获当前可见 CFI/像素偏移或 PDF 页内比例，停止后维持当前浏览位置，不能恢复旧朗读点。PDF 页尾在视口增高时被浏览器夹取后也要恢复；EPUB 显式选文起读优先于播放栏打开时的旧锚点。滚动容器关闭浏览器自动 scroll anchoring，避免与阅读引擎补偿重复。

## 当前三问撤销验收（1.1.10）

隔离 Vault 验证打开书籍、切换章节、原生回退、旧回答布局恢复均不调用 AI；无三问、答题、重新生成或出题设置入口。历史问题/回答/反馈/复习以及原书字节不变；旧草稿按 core/logic/retell 原顺序对应问题，切换语言和关闭重开不丢。笔记优先显示批注，历史默认折叠。双语/主题/七宽度检查四个阅读工具、两项章节导航及笔记可用；主动 AI 解读、明确保存批注、查词/生词删除继续验收。下文早期三问/回答流程已退休，只保留历史规则供追溯。

构建命令为 npm run build（TypeScript 检查及 esbuild）。修改进行中不重复构建；所有工作面合入后统一执行。

语言修改须在实际隔离 Obsidian 中验证原生下拉保存/重开、旧配置默认、非法值回退、界面/ARIA/命令/标签页更新；切换时阅读 iframe/document/engine 与 CFI 不变，回答、批注和设置草稿不丢。中英文各检查浅/深色、四页面、窄/宽屏，英文长标签不能溢出。协议端点覆盖中英默认三问、解释、反馈、自定义模板保留、空白回退、中英/JSON 标签与无效响应不落盘；AI 协议固定回复不能当作真实模型质量证明。比较既有历史和原书字节，禁止用翻译迁移用户数据。

## 必验行为

- 实际 Obsidian 隔离 Vault 导入并阅读 EPUB、PDF、FB2（独立/ZIP）、MOBI/KF8、CBZ；验证自然页序、目录/正文、翻页及退出重开位置。
- 新文字格式的批注 CFI 须返回同一原文；现存 EPUB/PDF 的定位、高亮、批注、题目版本、回答/反馈/复习跨重开保持不变。CBZ 只保存图页位置，无三问、文字批注或复习请求。
- 故意传入格式错误、损坏归档与 DRM 文件；确认错误发生于写盘前。比较导入文件与阅读库原书的字节。
- DeepSeek/Agnes 以隔离兼容端点验收官方 URL、模型、各自 Authorization 与无串钥；覆盖 legacy flat settings、探针、错误脱敏、视图重开和请求中途修改配置。没密钥时不得声称真实供应商连接或模型质量。
- 关闭、重载以及打开尚在恢复中的阅读书时，不得丢最后阅读位置、迟到更新已卸载 View，或在读书引擎已销毁时保留内容 hook/listener。
- 三问可全部略过或只记一题；保存不请求 AI。可选参考评价失败重试不重复保存，Markdown 写失败撤销本次记录；历史题目版本、回答和评价完整。
- 笔记页直接展示三问、历次想法/参考评价和批注；旧复习 View 状态映射笔记页。原预约数据保留，不再新增、消费或生成任务。
- 损坏、恢复、并发写入和写后不一致时不丢历史。
- 320/375/414/768/1024/1280/1440px 窄宽面板无横向溢出；浅深色与键盘可用。
- EPUB 长按/选区自动滚动扰动后仍在同一整页与 CFI；复制原始文字、关闭面板、翻页、隐藏阅读页返回、重开与模式切换不得丢位置。PDF 跨页复制保持全选区，但批注引用与定位仍限定单页。
- 笔记删除确认跨异步库通知不消失；取消无变化，确认后 `reading.json`、`批注.md` 与可见高亮一致。长中文书名可导入、显示并从磁盘封面缓存重开。
- AI 解读关闭后迟到结果不显示也不保存；显式存入只产生一条批注。三问从第三题直接保存、跳过空题、版本切换保留草稿、保存及参考评价失败重试均保持版本与记录一致。
- 1.1.2：提示词保存/重开/清空、正文替换与无占位符追加、无效响应不落盘；同一 leaf 连续四页面与原生前进回退，CFI、未提交草稿和问题版本稳定，无后台 iframe/订阅残留；短按保存、长按选色松手不保存、取消不保存、EPUB/PDF 颜色重开和旧黄色；分类新增/分配/搜索组合/已读切换及持久化、首屏四卡。七种宽度浅深色需等待 EPUB resize 250ms 完成再评估稳定布局。
- 1.1.3：两列两行四本及实际图片比例、第五本翻页/筛选搜索重置/回退页码/范围夹取；所有选文按钮无可见文字且有可访问名称，44px 主排五图标始终一行，二级色圈/更多操作不换行。复制/AI 解读/批注/取消批注/取消画线确认仍可用；方向下键/Escape、长按释放与选色不落盘、EPUB/PDF 颜色持久化；四种阅读底色下色块无外框/底边，转换文字格式使用同样绘制。验收产物和公开 Release 附件逐字节一致。

测试只验证消费者可见行为和边界，不检验源代码措辞、属性转发或无意义默认值。暂时的协议服务只可用于验收，不能成为插件假 AI 功能。没有真实供应商密钥时明确报告未验证外部模型。

## 手机键盘验收（1.1.9）

在独立 Obsidian 验证不自动打开键盘；手机点击输入后普通题目、textarea 与三个按钮都位于可视范围，长草稿内部滚动不带走问题。分别约束视觉视口高度/偏移和整个窗口高度，双语主题七宽度不溢出；长自定义题独立滚动可完整回看。验证语言重绘的文字/光标/输入滚动、切题、失焦恢复历史、缺 VisualViewport 回退、关闭后的监听/观察器/帧释放、保存不改变旧笔记。模拟键盘可视区不等于 Android/iOS 原生输入法验收，必须区分报告。
