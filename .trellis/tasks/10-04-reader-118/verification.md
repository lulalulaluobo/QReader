# 1.1.8 引导性阅读与笔记验收

## 实现

- 复习入口改为笔记，取消复习任务/预约界面及相关写入方法。旧 `qreader-review` 布局注册为 NotesView；保留旧命令 ID 以兼容快捷键，其可见名称为“打开笔记”。
- 阅读三问可以略过或只保存部分；保存不请求 AI。读者主动获取参考评价，新提示词只发送已记录的问题/想法，允许不同解读、不评分、不生成标准答案。旧评价与复习记录不迁移。
- 每书 `reading.json` 为真源，沿用 `批注.md` 保存问题版本、全部阅读想法、已完成旧复习、参考评价及批注。三问生成、想法保存、评价附加通过 JsonStore 事务队列同步；写失败回滚，可重试。
- 笔记页按书/章回看，最近想法默认展开，较早问题版本收纳；阅读笔记面板显示本章三问/想法。保存后可补充记录、查看笔记或返回阅读。

## 验证

- `npm run build`、`npm run test:notes`、`npm run test:translation`、`git diff --check` 通过。
- `tests/reading-notes.mjs` 验证部分回答、问题版本对应、旧完整/部分回答和复习、双语参考协议、无回答不请求 AI、严格响应解析、Markdown 内容、附属文件失败回滚/重试及现有记录引用稳定。
- 实际 macOS Obsidian 1.13.7 独立 Vault 安装最终 1.1.8 三文件，`notes-118-test.mjs` 验证从第三题直接保存且无 AI 请求、直接查看旧记录、评价失败/重试不重复记录、Markdown 写入失败/撤销/重试、离页阻止迟到评价、原生后退恢复已保存记录并再获取评价、空题跳过、草稿/问题版本/CFI/语言切换、阅读笔记面板和旧复习布局。
- 双语浅/深色与 320/375/414/768/1024/1280/1440px 共 56 组笔记/想法布局无横向溢出。17 本隔离书原文件 SHA-256、旧问题版本、旧回答/复习及批注与开始快照一致；未处理异步错误为空。截图 `tmp/release-112-smoke/notes-118-en.png`。
