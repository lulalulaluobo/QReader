# 1.1.2 隔离验收记录

日期：2026-10-04。环境：macOS、Obsidian 1.13.7；独立 Vault 位于 `tmp/release-112-smoke/vault`，仅使用测试样书和本地兼容 AI 端点。没有修改用户实际书库或供应商凭据。

## 实现与证据

- 默认三问模板按用户原文实现，设置可编辑、保存、重开、清空恢复默认。实际兼容请求包含替换后的完整章节正文，无占位符时追加正文；空白采用默认模板，已有题目缓存不会再次请求。中文标签和原有 JSON 均可用；重复类型、空题、多余标签、重复题被拒绝且不写入新版本。
- 书架→阅读→第三题回答→原生回退→前进→复习→复习回答→回退使用同一 leaf ID，总 leaf 数不增长。阅读页销毁后没有 iframe 残留；回答页仅一份库订阅、没有阅读设置订阅。CFI、第三题草稿、题目版本、书架搜索/分类和复习筛选恢复。
- 实测发现 `getLeaf(false)` 对自定义视图仍会新建页，改为 `getMostRecentLeaf()`；四个 ItemView 必须启用 `navigation = true`，并保留宿主的 history 标志，原生前进/回退才会记录跨视图历史。
- 重新出题始终追加版本，保留尚未提交的草稿所引用的旧题。三题统一提交，反馈 503 后重试没有重复保存答案；闭卷复习完成前不显示旧答案，完成后显示本次及历史。
- 原生指针长按 450ms 展开颜色；松手及选色均不写记录，短按才保存。已有绿色标记可改色，取消紫色草稿不新增记录；EPUB、PDF 重开恢复颜色，缺色的旧记录继续黄色。四种阅读背景下菜单有宿主底色、边框和阴影，并保持在手机视口内。
- 分类新增和分配、分类结合搜索、已读/未读过滤、原生回退及磁盘持久化通过。对比分类修改前后，章节历史、进度和批注完全相同。七种宽度的浅深色书架 14 组通过，回答/复习/阅读 42 组通过；375×667 移动 CSS 模拟首屏两列四卡完整位于底部导航上方。
- FB2、真正 MOBI6、KF8/AZW3、CBZ 导入、阅读、翻页、单页导航和重开位置回归通过；与 EPUB/PDF 检查合计覆盖六类。落盘原书与源文件字节相同，CBZ 无文字三问/批注。MOBI/KF8 样书来自 Project Gutenberg《Alice's Adventures in Wonderland》。
- 六格式回归发现部分转换书籍第一次排版完成后，初始 CFI 会落到上一页；保持中间定位不落盘，在首次布局测量后再次应用已保存 CFI，AZW3 及其余格式重开回归通过。各页面 onOpen 立即同步宿主阅读 chrome，避免导航后保留过期布局。
- 三问弹窗 Tab 焦点约束与 Escape 关闭通过；关闭阅读页后沉浸 body class 移除，运行期间未捕获未处理错误。TypeScript/esbuild 生产构建及 `git diff --check` 通过。
- 导入真实长英文书名后补齐复习书籍按钮的自动换行、44px 触摸区及窄页标题/标签换行，320px 复习页不再由最长书名撑出横向滚动。

## 验证边界

移动端为 macOS Obsidian 的窄窗口及移动 CSS/指针模拟，没有 Android/iOS 真机验收。AI 使用本地 OpenAI-compatible 协议服务，验证请求、解析、版本与失败处理，没有验证真实供应商输出质量。
