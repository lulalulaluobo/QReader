# 翻页稳定与独立朗读

## 用户修正

- 上下翻页和停止朗读回到阅读时出现乱跳，需要排查修复。
- 同一本书内手动翻页不能停止朗读；朗读与读者浏览位置独立，只有停止按钮主动退出朗读。
- 替代此前“手动翻页/跳章停止朗读”的规则；不沿用旧验收结论。

## 行为目标

- 默认继续短句标色与自动跟随。读者主动翻页、滚动或跳章后进入自由浏览，音频沿原序列继续，不抢回阅读页面。
- 暂停再继续或明确选文起读可以重新跟随朗读；不增加常驻按钮，也不强制重新播放书本。
- 停止按钮只停止音频、清理临时标色和控制栏，重排保留当前阅读文字位置，不跳回旧朗读位置。
- 连续上下/左右翻页与快速相反方向操作保持顺序，播放/停止/工具栏展开收起的重排不夹入旧定位。
- 换书、退出阅读页与卸载仍释放已销毁阅读器的音频；没有后台孤立引擎。

## 实现与验收

复用现有 EPUB.js CFI/队列与 PDF 文字/页面位置，结合已安装源代码分析重排事件，不改持久定位格式或引入新依赖。独立 Vault 验证真实滚动、快速翻页、播放中翻页不停止、不抢位置、停止前后原文锚点稳定、迟到定位，以及原书/笔记/生词完整。没有 Android 设备则明确测试范围。更新双语说明、小版本 Git 与正式 Release。
