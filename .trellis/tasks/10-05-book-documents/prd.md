# 1.2.1 一本书一份阅读笔记

用户确认撤下思考线，QReader 专注于阅读、摘抄、批注与整书想法。跨书关系留给之后本地 LLM 读取普通文件处理。

- 撤下思考线视图、搜索/关联生成、确认/维护及 AI 关系请求；移除 MiniSearch。保留原有阅读、查词、选段解读、颜色、分类和中英文设置。
- 每书沿用批注.md，阅读中持续汇总所有摘抄（含纯高亮）、自己的批注、已有整书想法、日期与原文定位。旧三问/回答/评价/复习只作折叠历史，不产生任务。
- 笔记页以实际 Markdown 文档为准，按书选择、阅读预览、在普通 Obsidian 编辑器编辑；自由整书想法直接写在文档中，不强制标签、问题或模板。
- 日期区分最近阅读与最近笔记。书名/作者、原书链接和章节位置可直接阅读；定位链接延续旧版协议。
- 保存/修改/删除正文批注和阅读退出同步文档，不逐页重写 Markdown。用上次生成基线、当前手工文档、新输出三方合并；手工文字保留，同处更新双方保留并标明同步补充，不引入必须处理的冲突待办。
- notesSync 在 reading.json 保存生成基线、最终文档校验和及已观察到的手工修改时间。与 Markdown 共用原有串行 JSON 事务；回读校验，外部变化不覆盖，附属文件失败回滚原文档和 JSON。
- 使用成熟 node-diff3 的三方文本合并，克隆参考源码至 references；不引入全文检索或数据库。
- 旧 .qreader/thinking.json 保留不改；若有旧记录，一次性导出为普通旧版记录 Markdown，包含已写个人判断/问题/原关联说明和可用来源。归档文件不覆盖手工编辑，损坏旧数据不妨碍阅读。
- 既有 reading.json/原书/vocabulary.json 不迁移或删数据。保留笔记历史及旧布局的未提交草稿。外部编辑的正文以 Markdown 预览显示，插件内的正文批注继续保留定位记录；重叠编辑时双方均保留。
- 验证纯高亮汇总、手工追加/改字/删段保护、同处更新与重复同步、基线升级、故障回滚/外部变更/并发、归档无丢失/不覆盖、真实协议定位、语言/草稿/七宽度主题、被动零 AI、原书/旧历史/生词完整。独立 Obsidian 验收，手机仅模拟时明确说明。
- 更新双语 README、版本和测试；推送远程 Git 并发布 1.2.1，四附件/ZIP/源码校验一致。
