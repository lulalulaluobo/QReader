# 阅读页听书

## 用户决定

- 桌面、移动端都在阅读页听书；主要手机是 Android。
- Android 必须留在 Obsidian 内，可以采用其他语音方案。
- 从当前阅读位置开始，正文标示当前朗读句子，自动跟随翻页。
- 沿用现有图标、语言、阅读背景与轻量笔记设计。
- 用户要求播放布局进一步简洁：默认只显示四项单行控制栏，声音设置在二级面板中，正文不遮罩。

## 实现

- 桌面优先 Web Speech 系统语音；Android WebView 不支持此接口，自动采用 Bing 在线语音。两种方式均可手动选择。
- Bing Translator HTTP SSML 合成已实际验证中文 MP3：随机 IG、页面短期 token、无个人密钥；只借鉴 GTranslate 的协议，不引入 C# 运行库。
- 在线模式仅在读者播放后发送当前短句，至多预取下一短句；不上传整本书，不永久保存音频。
- 引擎按 EPUB spine / PDF 页读取短句和原文定位，逐句朗读、临时高亮、自动跟随。不改动正文或持久化批注。
- 播放、暂停、停止、语速及中英文声音。停止、换书、离开阅读页立即释放音频和临时高亮。请求回包不能恢复已停止的播放。
- EPUB / MOBI / AZW3 / FB2 和含文本的 PDF 可朗读；图片漫画 / 扫描 PDF 没有文字时明确说明。
- 首版跟随以短句为单位，不声称云语音提供逐字时间戳。网络服务异常允许重试及切换系统语音，不悄悄切换服务。

## 验收

- 桌面原生 Obsidian 验证当前位置起读、暂停续读、停止清理、跨页跟随；使用真实 Bing 音频解码并验证请求与取消竞争。
- 测试中英文、七个响应宽度、阅读主题、源格式，原有笔记和阅读资料完整。
- Android 共享 Obsidian requestUrl + HTMLAudio 播放路径；若无真实 Android 设备，明确说明未做真机验收。
