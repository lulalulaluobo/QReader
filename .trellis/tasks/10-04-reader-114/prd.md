- 更新 README.md，推送 Git 与补丁 Release。

## 决策
- `settings.language` 为 zh-CN/en，旧配置默认简体中文，非法值回退中文。沿用 DOM/原生 Setting/Lucide/现有通知机制，不增加依赖。
- 集中维护类型安全中英消息表，四页面、设置、图标可访问名称、菜单、状态及已知错误均本地化；原书/用户文本与持久化键保持原样。
- 空白三问提示词根据所选语言使用等价的原子三问模板；自定义模板原文保留。解释与反馈默认系统/用户提示词也按语言切换，JSON 存储字段不变；解析接受中文标签、英文标签和既有 JSON。
- 切换语言不迁移题目/答案/笔记，也不为了更新阅读按钮而重开引擎；保留 CFI 与未提交草稿。已生成内容仍为生成时语言，新的请求使用当时设置。
- 沿用 existing references/qiaomu-reader 的原生 DOM/Obsidian 设置方式，仅自行实现两种语言的轻量消息表，不引入通用 i18n 框架。
- README 新增双语安装、功能、语言与提示词说明。发布 1.1.4，保留历史标签。
