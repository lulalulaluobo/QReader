# 参考阅读器改版与 AI 预设

## 目标
克隆用户指定的 qiaomu-reader，借鉴书籍适配与沉浸阅读实现；按用户提供的微信读书布局改版 QReader 阅读页，增加 DeepSeek 和 Agnes 两个预设，用户只需填写各自 API Key。

## 已确认事实
- 参考仓库：https://github.com/joeseesun/qiaomu-reader，克隆到 references/qiaomu-reader。
- QReader 当前为 Obsidian 插件，使用原生 ItemView、普通 TypeScript/CSS、epub.js 与 PDF.js，已支持 EPUB/PDF。
- 既有功能：本章三问、闭卷回答、复习、选文菜单、划线/批注分离、reading.json 串行事务及批注 Markdown。
- 用户图片：纸感浅底正文、小号章节标题、底部位置提示；中央点击呼出底部工具栏；字号/行距/边距面板、颜色/背景面板、按章节的笔记列表。
- 模型已从官方资料核实：DeepSeek 最新 Flash 模型 ID deepseek-flash（V4.1 Flash），OpenAI 兼容地址 https://api.deepseek.com；Agnes 模型 agnes-2.5-flash，地址 https://apihub.agnes-ai.com/v1。

## 要求
- 阅读期间去掉下方宿主网页导航栏，退出阅读/切换其他页/卸载插件后恢复；不得永久改变用户宿主设置。
- 图片只作为阅读布局与设置面板参考，不加入未要求的阅读统计、听书、自动翻页等功能。
- 默认正文为视觉中心，中央点击显示/隐藏操作区；保留三问、完成本章、目录和划线/批注功能。
- 可调整字号、行距、边距、字体、首行缩进、翻页方式、阅读配色；设置持久化且不破坏定位和高亮。
- AI 设置提供 DeepSeek/Agnes 两个按钮，自动配置已核实的模型与兼容地址，只要求填写 API Key；切换服务不得向另一家发送原服务密钥，旧自定义配置保留。
- 用户已选择完整六格式：EPUB、PDF、FB2、MOBI、AZW3、CBZ；保留现有 EPUB/PDF 引擎与定位，新格式用 MIT 上游解析后仅在内存构造 EPUB，原书和实际格式仍写入阅读库。
- CBZ 没有文字层时只提供图片阅读和位置保存，不伪造三问、闭卷回答、文本批注或复习内容。
- 参考项目 GPL-3.0-only；仅调研实际路径与多格式/活动视图机制，不将其源文件实现复制至 MIT QReader。沿用 MIT Foliate.js/fflate/JSZip 等独立许可依赖的接口与许可证声明。

## 布局决策
- 阅读页采用用户指定的微信读书式布局，不另做审美选择：轻量章节题头、纸感正文、真实位置提示；中央点击呼出顶部返回和底部操作。
- 底部入口为目录、三问、笔记、字体排版、背景，保留完成本章；不加入听书和统计。
- 字体排版与背景分别作为底部面板；笔记按章节和原文位置分组，可跳转原文或编辑已有记录。
- 项目记忆统一写入本任务及 .trellis/spec，沿用 PRD.md 的产品事实，不新增竞争性的顶层 PRODUCT.md/DESIGN.md。

## 边界
不改书架/回答/复习的产品流程，不加入常驻聊天、评分、听书、阅读时长统计，不覆盖用户真实书籍或密钥。不将参考项目的旧模型名当作最新 API 配置。
