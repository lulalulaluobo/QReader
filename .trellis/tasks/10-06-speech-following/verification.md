# 1.2.5 验证记录

日期：2026-10-06。目标：允许临时手动浏览，同时在声音进入下一朗读页时自动返回原文并恢复跟随。

## 实现

- EPUB 在跟随时记录原朗读视口最后一个可见字符的 CFI。手动翻页后冻结此边界，下一句越过边界便恢复跟随。采用实际字符而非依赖空格的页尾映射，支持长中文段落与换行末尾的光标位置。
- PDF 记录原视口最后一个可见文字项及其结束偏移；同页跨屏、物理跨页均恢复跟随。用户重复翻页不会改变原朗读边界。
- 保留 1.2.4 的导航队列、迟到请求取消和停止时的位置快照；不改变声音队列、设置及持久存储结构。

- `npm run test:speech` 及翻译、笔记、文档测试：通过。
- `git diff --check`、Trellis 任务上下文校验：通过。

## 独立 Obsidian 验收

使用项目 tmp 内的独立 Vault、Electron 配置及插件副本，未操作实际用户 Vault。

- EPUB/PDF × 翻页/滚动 × 375/768 宽度，共八组通过。用实际原文字形是否进入视口独立选择跨页句，确认当前朗读页内不抢回页面，下一朗读页自动返回，返回后连续跟随。
- 多次手动翻页保持原边界；再次临时浏览后第二轮返回有效。排队的用户跳转后，新的下一朗读页定位优先完成。
- 保持同一个暂停播放器及其原文序列。停止后滚动模式的 CFI/像素位置、PDF 页码/比例不变；翻页模式保留原位置所在重排页。
- 真实 Bing requestUrl/HTMLAudio 自然续句跨过页边界后自动返回，音频继续，未以固定播放回复替代。
- 六格式 MOBI/AZW3/FB2/PDF/EPUB/CBZ 的朗读边界与切书检查通过；CBZ 无可朗读文字时不创建文字边界。
- 36 个受保护文件的 SHA-256 保持，覆盖原书、生词及笔记正文；只规范化既有最近阅读时间字段的正常变化。

系统语音的原文加载、暂停队列与控制器自动测试通过。本轮隔离 Electron 的系统语音未发出 start 回调，未计作实际发声验收；自然播放续句使用真实 Bing 在线音频验证。Android 未连接真机，375/768 为桌面视口模拟。
