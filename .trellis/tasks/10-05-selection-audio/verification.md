# 1.2.3 选文起读验收

## 实现

- 单行选文菜单增加纯播放图标，保留 44px 触控区与双语可访问名称。底部播放键、先打开听书控制栏再播放，以及已有划线/批注都可以采用原文起点。
- EPUB 把选区 CFI 收拢到起点，再从包含起点的完整短句向后朗读；PDF 用页码、文字项及字符偏移定位，不用字符串搜索。同一文字项中较后的句子和多项跨句均保留正确的原文字段。
- 显式起点替换旧批次、暂停句与等待中的合成，取消逻辑代次防止旧请求恢复播放。起点只存阅读页内存，停止/导航/换书清理；没有选区时保留原位置起读和暂停续播。

## 自动检查

`npm run build`、`npm run test:speech`、`npm run test:translation`、`npm run test:notes`、`npm run test:documents`、`git diff --check` 均通过。

听书测试新增 PDF 同项重复句定位、句中起点恢复完整句、多项跨度、正常可见项起读、播放/暂停改选位置、顺序跨章节、停止清掉起点、迟到原文加载和迟到在线语音不得恢复旧位置。沿用供应商协议、所有权和取消回收测试。

## 原生隔离验收

使用现有独立 Vault `tmp/release-112-smoke/vault` 与隔离 Obsidian，未修改用户实际 Vault。

- 实际系统朗读与 Bing requestUrl + HTMLAudio 在线朗读均从选区起点开始；重复 EPUB 句子通过不同 CFI 定位到后一处，句中选区完整起读，CSS 临时标色与原文一致。
- 选文播放、底部播放、先开控制栏后播放、暂停续播/改选、已有标记均通过；PDF 真正 TextLayer 选区定位与短句标色一致。
- EPUB、PDF、FB2、MOBI、AZW3 起点与原文对应；图片 CBZ 无文字。2 语言 × 4 主题 × 7 宽度共 56 组验证六图标主排单行、无可见文字、ARIA、44px、无横向溢出。
- 比较 17 本原书、生词文件的字节，历史章节/问题/回答/批注/整书想法，及笔记文档正文；仅排除原有中文/英文“最近阅读”时间行的正常更新。
- 原生验收脚本：`tmp/release-112-smoke/audio-123-selection.mjs`；截图：`tmp/release-112-smoke/tts-123-selection-mobile.png`。手机为桌面视口模拟，Android 尚未真机验收；不保证锁屏/后台连续播放。
